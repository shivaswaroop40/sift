ExpertFlyer has launched an automated alerts feature for Premium and Elite members that creates three standard alerts, covering flights, schedule changes and aircraft swaps, when users forward a booking confirmation to createalerts@expertflyer.com. Members can save default preferences and set up auto-forwarding so alerts are created without manual input after each booking.

A separate disruption alert tool, currently in public beta, monitors cancellations, delays and schedule changes for Premium and Elite users. When a disruption exceeds a set threshold, ExpertFlyer emails alternative flight options, each with a short justification, plus the airline's stated reason for the disruption.

One current limitation is that disruption alerts only consider a single leg on multi-leg itineraries, though ExpertFlyer says a fix is in development. The company has also added a beginner-friendly blog and free monthly webinars open to all members.

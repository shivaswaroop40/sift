Threat actors compromised Microsoft's agent-framework package on PyPI and pushed a credential stealer. Versions 1.26.1 and 1.26.2 were published 33 minutes apart on 17 November 2026. They are designed to run the stealer every time Python starts.

Reports came from Aikido, Chainguard, Endor Labs, OX Security, SafeDep, Socket, StepSecurity and Wiz. The headline says the malware targets cloud credentials. The source text is truncated, so it does not say how the package was compromised or how long the versions stayed live.

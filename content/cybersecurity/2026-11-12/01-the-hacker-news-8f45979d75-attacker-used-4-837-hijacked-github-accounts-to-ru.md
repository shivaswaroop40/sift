Aikido Security says an attacker began using stolen credentials for 4,837 GitHub accounts on Tuesday. The attacker planted a secret stealer in repositories those accounts could write to. The malware ran in at least 1,806 repositories.

The stealer targets secrets and cloud credentials that a repository's CI workflows can reach. Aikido's account suggests the attacker has likely collected some of these. The source text is truncated, so the scale of what was taken is not stated here.

Attackers are exploiting an unpatched vulnerability in Magento Open Source and Adobe Commerce that allows remote code execution on online store servers without authentication, according to Dutch security firm Sansec.

Sansec named the flaw StyleSmuggler and reported that exploitation began on September 4, with the advisory issued on September 5. The vulnerability enables attackers to run malicious code directly on the server, which is typically used to plant persistent backdoors for later access.

For security and platform engineers running Magento or Adobe Commerce, this means any unpatched store is likely being targeted and may already be compromised. Immediate investigation for indicators of compromise is warranted, even though no patch is currently available.

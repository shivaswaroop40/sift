Microsoft has reported an 'agentic threat actor' called JadePuffer that compromised an Azure tenant and deleted storage, applications, and databases in what it describes as a destructive cloud attack.

The attacker is believed to have used exposed credentials to reach the environment, after which it carried out destructive activity against cloud-hosted data and services rather than stealing or staging it.

The report does not detail which credentials were exposed or how long the attacker dwelled before acting. The incident is one of the first public cases tied to an 'agentic' label, though Microsoft has shared limited technical evidence so far.

For defenders, the case is a reminder that credential hygiene remains the entry vector, and that attackers with cloud access can move quickly from initial foothold to destructive action.

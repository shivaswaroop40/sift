Microsoft patched 1,260 vulnerabilities this month, according to SANS ISC. Of these, 68 are rated critical and 167 are Chromium issues affecting Edge. One flaw is already being exploited: CVE-2026-124194, a spoofing vulnerability in Outlook. The diary attributes the volume to an AI-induced patch surge.

Other items of note include CVE-2026-119958, a critical remote code execution flaw in Microsoft LDAP. Five critical flaws affect Microsoft Queuing and Queue Manager. CVE-2026-113859 is a Windows TCP/IP remote code execution bug with a CVSS score of only 7.5.

The listing also covers many .NET, ASP.NET Core, Azure and Active Directory Domain Services fixes. These include an Azure DevOps Server remote code execution flaw at CVSS 9.9 and an Azure OpenAI privilege escalation rated critical at 9.8.

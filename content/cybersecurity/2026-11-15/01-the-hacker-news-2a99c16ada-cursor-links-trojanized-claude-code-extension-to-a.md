Cursor says the compromise of Anthropic's official Claude Code extension on its extension marketplace came from a stolen access key. The key had been issued by Cursor to Fireworks AI. Cursor says Fireworks exposed it, following a breach at Fireworks.

In a Friday update, Cursor said the attacker used the key to copy data from a read-only resource. The source text is truncated at that point, so it does not say what was copied or how that led to the trojanized extension.

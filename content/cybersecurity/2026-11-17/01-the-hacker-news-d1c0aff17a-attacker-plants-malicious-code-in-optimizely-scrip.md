An attacker exploited a flaw in Optimizely Web Experimentation and planted malicious code in some of the scripts that customers' websites load from the service. Optimizely disclosed this early today. Report URI, which monitors the scripts websites run, says visitors to sites run by at least 178 organisations received the code yesterday.

Report URI names CNN, the BBC and Zoom among the affected organisations. The headline says the code served a card skimmer and iOS exploit kits, but the source text is cut off before it describes what the code did.

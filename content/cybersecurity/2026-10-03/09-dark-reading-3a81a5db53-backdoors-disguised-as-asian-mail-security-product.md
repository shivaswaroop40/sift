Three new Linux backdoors have been discovered that impersonate legitimate mail security software commonly deployed in Asian environments. The malware mimics trusted edge solutions, allowing it to evade detection by blending into typical enterprise infrastructure.

The threat matters because mail gateways are critical chokepoints in network defence. An implant that poses as legitimate security software gains both persistence and trusted network access, while remaining invisible to systems administrators who expect to see that software running.

The disguise technique exploits the assumption that security tools are trustworthy. Defenders cannot rely on process names or service descriptions alone to verify legitimacy of running services.

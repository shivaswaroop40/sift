Researchers discovered a campaign using Anthropic's Claude Code as an AI orchestration layer to guide commodity tools like Cobalt Strike. The attackers targeted WordPress sites, e-commerce platforms, and critical infrastructure in Ukraine, stealing over 628,000 records.

The use of AI to coordinate attack tools represents a shift in how initial access campaigns are run. Rather than manual operation, Claude Code automates decision-making and tool deployment, potentially allowing smaller teams to scale attacks.

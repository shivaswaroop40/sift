Dark Reading reports a vulnerability dubbed Java4Shell in the OpenJDK runtime. It is described as a memory corruption flaw that was discovered using AI. The report says unauthenticated attackers could use it to take over affected systems.

The source text available is only a short standfirst. It gives no CVE identifier, affected versions, severity score, patch status or evidence of exploitation in the wild. Claims about global enterprise exposure cannot be checked from this text.

If confirmed, a flaw in the OpenJDK runtime would touch a very large number of Java applications and services. Teams should find where OpenJDK runs in their estate, including bundled runtimes and container images, and watch for vendor advisories.

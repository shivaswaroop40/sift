Amazon Threat Intelligence says suspected China-linked hackers used autonomous AI agents to find a previously unknown flaw in MONAI Label, an open-source medical imaging server. They then used it to gain root access to a university server.

The flaw lets an unauthenticated attacker write files outside the server's storage folder. It affects MONAI Label 0.8.5 and earlier in the default setup. The source text is truncated, so further technical detail and any fix status are not given here.

CISA added CVE-2026-104286 to its known exploited vulnerabilities list after reports of active attacks. The flaw in Fortinet FortiMail scores 9.8 on CVSS and permits unauthenticated attackers to write arbitrary files to the system.

This matters because FortiMail is widely deployed as an email security gateway. Arbitrary file write access on an unauthenticated basis can lead to full system compromise, malware placement, or configuration tampering without any credential requirement.

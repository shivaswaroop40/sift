Apple is tightening controls on macOS Full Disk Access, a broad permission that grants applications read access to nearly all user files. The move targets developers using this permission for AI agents in ways that could expose sensitive data including files, email, messages and browsing history without clear user awareness.

Full Disk Access is a legitimate need for some software, but it presents a risk when AI agents operate with it. An agent running under such permissions can read everything on a user's system, and the user may not understand what data the AI can actually access or how it will be used.

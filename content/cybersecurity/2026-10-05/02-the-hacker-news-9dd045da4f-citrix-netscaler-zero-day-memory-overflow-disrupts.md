Citrix has patched CVE-2026-88779, a memory overflow flaw in NetScaler ADC and Gateway with a CVSS score of 8.7. The vulnerability is being actively exploited in targeted zero-day attacks.

This matters because NetScaler is often positioned between users and internal applications that rely on SAML for authentication. Successful exploitation can knock SAML deployments offline, preventing legitimate access to protected resources.

The vulnerability affects both NetScaler ADC and NetScaler Gateway products, suggesting broad exposure across organisations using Citrix for authentication and access control.

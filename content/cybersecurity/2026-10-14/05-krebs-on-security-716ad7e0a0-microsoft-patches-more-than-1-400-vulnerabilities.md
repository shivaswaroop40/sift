Microsoft issued fixes for over 1,400 security flaws this month, including 78 critical vulnerabilities that allow unauthenticated code execution. One zero-day in Windows Shell (CVE-2026-96951) was already exploited in the wild. A second flaw in .NET Framework was publicly disclosed before the patch, giving attackers a head start.

The volume far exceeds historical norms. September saw nearly 1,000 fixes. Microsoft has now crossed 4,000 CVEs patched this year with two months remaining, surpassing the full-year 2020 record of 1,261. The company attributes the surge to large language models accelerating vulnerability discovery and patch development.

Security teams face operational strain testing and deploying such volumes without breaking dependent systems. Only 26 Microsoft CVEs appeared in CISA's Known Exploited Vulnerabilities catalogue so far this year, providing a prioritisation anchor. Teams without capacity to validate all patches should prioritise those 26 known-exploited flaws first.

Amazon's threat intelligence team says AI agents operated by attackers have been searching internet-exposed AI applications for weak spots. Named targets include LiteLLM, One API and Dify. The aim is to steal the AI provider keys stored inside these apps.

Amazon captured the agents' own records using decoy servers. The records describe stolen keys being used to run the AI models that powered the search for further keys. That makes the campaign partly self-funding, at the victims' expense.

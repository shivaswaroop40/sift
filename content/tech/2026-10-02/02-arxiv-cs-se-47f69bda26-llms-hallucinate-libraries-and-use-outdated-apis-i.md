Researchers analysed 100 code files generated by large language models and found library-related errors in 84% of them. The most common problems were incorrect import paths, missing imports, hallucinated (nonexistent) libraries, deprecated API calls, and unused imports.

Library errors matter because they cause compilation and runtime failures that break the reliability of AI-assisted development. Practitioners using LLMs to scaffold code with external dependencies face immediate breakage without intervention.

The authors tested an agentic approach using task analysis, documentation grounding, validation loops, and iterative generation on 300 tasks spanning Python frameworks like LangChain and AutoGen. Their system reduced library errors by 38-55% across five models including GPT-4, DeepSeek-V3, and Llama 3, improving overall correctness by up to 16%.

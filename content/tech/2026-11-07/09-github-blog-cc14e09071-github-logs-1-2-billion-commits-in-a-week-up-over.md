GitHub says it logged more than 1.2 billion commits in a single week this October, over 400% more than a year earlier. The figure opens a blog post introducing a guide to what GitHub calls agentic engineering, its argument that AI has made code generation cheap while the rest of the workflow lags. The post cites a Faros AI study on pull request pressure, though the excerpt cuts off before its finding.

For anyone running review queues, CI or storage, commit volume is a leading indicator of load. A 400% year-on-year rise means far more code arriving for review, testing and retention, whatever the per-commit quality. GitHub's own framing, that developers do not feel 400% more productive, concedes the gap between generation speed and everything downstream of it.

Two caveats. The numbers are GitHub's own platform data, published by the company selling Copilot, so the claim that the bottleneck now sits beyond generation is convenient. And the post says that single week beat GitHub's commits for all of 2025, which is impossible as written and reads like a typo for an earlier year.

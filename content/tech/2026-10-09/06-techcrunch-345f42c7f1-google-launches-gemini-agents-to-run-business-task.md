Google announced a unified Gemini agent that can plan and execute multi-step business tasks, not just answer questions. The agent receives objectives, connects to internal systems like Workspace, Slack, Jira, and databases, and maintains its own workspace account with email and audit trail. It can be called via tag, email, or group chat across iOS, Android, desktop, and third-party platforms.

For platform engineers managing enterprise systems, this matters because the agent integrates with your existing infrastructure—BigQuery, Snowflake, Postgres, MCP servers—and lets you control which model runs each task. Google prioritizes security and cost controls: users get visibility into the agent's reasoning, can override model selection, and set real-time spend caps.

Google launches with businesses first, where Gemini already has 90% Fortune 100 adoption, then plans consumer rollout. The agent can delegate work to subagents and load custom skills and code. Early adopters include PayPal, Shopify, and On.

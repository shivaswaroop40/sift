Cloudflare has acquired Deno, the JavaScript runtime created by Ryan Dahl. The company plans to use Deno's technology to improve its Workers platform, which runs code on Cloudflare's edge network. Deno recently released celld, an open source implementation of the Workers model.

Workers runs customer code across Cloudflare's distributed infrastructure. The acquisition gives Cloudflare direct control over runtime development and signals commitment to open standards. Deno's open source approach may reduce concerns about proprietary lock-in that some developers associate with edge computing platforms.

Deno had raised $26 million in funding including a Series A from Sequoia. The acquisition price was not disclosed. Dahl stated the goal is making the Workers model a mainstream approach to building servers.

A Harvard study of 700,000 engineers across 700 firms found that AI coding agents raised code commits by 20 percent and pull requests by 23 percent. Yet the number of resolved issues and shipped features showed no statistically significant change after tools were introduced.

Code review became the constraint. Review time increased 49 percent on average, with reviewers requesting changes on nearly twice as many pull requests and adding 35 percent more comments. A 14 percent increase in review staff offset any coding speed gains.

Humans still performed the vast majority of review work; AI agents contributed just 23 percent of review comments and 10.8 percent of pull request reviews despite 80 percent of firms using some AI code review by March 2026. The throughput benefit collapsed downstream.

Deno's team and founder Ryan Dahl are joining Cloudflare. The Deno runtime will receive bug fixes and security updates for one more year, then development ends. Deno Deploy shuts down in six months. JSR, the JavaScript registry, continues under Cloudflare.

The move reflects Dahl's shift from building a standalone runtime toward distributed application programming models. Cloudflare wants to merge Deno's work with its Workers and Durable Objects platforms, positioning this combined stack as the default for server development.

For engineers running Deno in production, this creates genuine risk. A year of maintenance is a tight window for migration planning. The move signals that as a platform, Deno lost the bet against Node.js ecosystem integration and specialised hosting.

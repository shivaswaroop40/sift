GitHub has released ReviewBench, an open benchmark for evaluating AI code review systems. The benchmark addresses a gap in measuring how well different AI reviewers perform at inspecting pull requests and catching issues before deployment.

Different code review AI systems have varying capabilities. Some surface more issues overall, some produce fewer false positives, and some excel at finding critical bugs while others catch minor improvements. A standard benchmark helps developers choose and compare reviewers for their needs.
